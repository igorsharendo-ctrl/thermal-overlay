Thermal — монитор температуры и загрузки CPU/GPU для Windows 11 x64.

Программа устанавливается для текущего пользователя, без прав администратора.
Все компоненты входят в этот пакет; интернет для установки не требуется.

При первом запуске Thermal проверяет поддержку температуры CPU. Если отсутствуют
драйвер PawnIO или служба ThermalOverlayCpu, программа объяснит их назначение
и предложит установку с отдельным запросом прав администратора Windows.
Без согласия драйвер и служба не устанавливаются. Имеющиеся компоненты используются повторно.

Удалить Thermal можно через «Параметры → Приложения → Установленные приложения».
Личные настройки, отдельно установленная служба CPU и общий драйвер PawnIO
сохраняются. Порядок их удаления приведён в README.md в папке программы.
